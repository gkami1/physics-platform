В цепи, схема которой показана на рисунке, напряжение источника ${U = 6\ \text{В},}$ сопротивления резисторов ${R_1 = 3\ \text{Ом}}$ и ${R_2 = 6\ \text{Ом}.}$ Амперметр и источник идеальные, сопротивлением проводов пренебречь.

![Схема: источник напряжения U, последовательно с ним амперметр и два параллельно соединённых резистора R1 и R2](../../assets/el-0040.svg)

Из приведённого ниже списка выберите все верные утверждения.

1. Общее сопротивление резисторов равно ${9\ \text{Ом}.}$
2. Сила тока в резисторе $R_1$ равна ${2\ \text{А}.}$
3. Амперметр показывает ${3\ \text{А}.}$
4. В резисторе $R_2$ выделяется бо́льшая мощность, чем в резисторе $R_1$.
5. Напряжение на резисторе $R_2$ равно ${3\ \text{В}.}$

## Решение

Резисторы соединены параллельно, напряжение на каждом ${U = 6\ \text{В}.}$

1. Неверно: ${R = \dfrac{3 \cdot 6}{3 + 6} = 2\ \text{Ом}.}$
2. Верно: ${I_1 = \dfrac{6}{3} = 2\ \text{А}.}$
3. Верно: ${I = I_1 + I_2 = 2 + \dfrac{6}{6} = 3\ \text{А}.}$
4. Неверно: ${P_1 = \dfrac{36}{3} = 12\ \text{Вт},}$ ${P_2 = \dfrac{36}{6} = 6\ \text{Вт}.}$
5. Неверно: ${U_2 = U = 6\ \text{В}.}$

Ответ: 23.
