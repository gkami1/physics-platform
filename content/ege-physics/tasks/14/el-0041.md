Источник тока замкнут на реостат. Идеальным амперметром измеряли силу тока в цепи, идеальным вольтметром — напряжение на полюсах источника при разных положениях движка реостата. Результаты:

- ${I = 1\ \text{А}:}$ ${U = 6\ \text{В};}$
- ${I = 2\ \text{А}:}$ ${U = 4{,}5\ \text{В};}$
- ${I = 3\ \text{А}:}$ ${U = 3\ \text{В};}$
- ${I = 4\ \text{А}:}$ ${U = 1{,}5\ \text{В}.}$

Из приведённого ниже списка выберите все верные утверждения.

1. ЭДС источника равна ${7{,}5\ \text{В}.}$
2. Внутреннее сопротивление источника равно ${1{,}5\ \text{Ом}.}$
3. При силе тока ${1\ \text{А}}$ сопротивление реостата равно ${6\ \text{Ом}.}$
4. Сила тока короткого замыкания источника равна ${7{,}5\ \text{А}.}$
5. При силе тока ${3\ \text{А}}$ в реостате выделяется мощность ${4{,}5\ \text{Вт}.}$

## Решение

При росте тока на ${1\ \text{А}}$ напряжение падает на ${1{,}5\ \text{В},}$ поэтому ${U = \mathcal{E} - Ir}$ с ${r = 1{,}5\ \text{Ом}}$ и ${\mathcal{E} = 6 + 1 \cdot 1{,}5 = 7{,}5\ \text{В}.}$

1. Верно.
2. Верно.
3. Верно: ${R = \dfrac{6}{1} = 6\ \text{Ом}.}$
4. Неверно: ${I_{\text{кз}} = \dfrac{\mathcal{E}}{r} = \dfrac{7{,}5}{1{,}5} = 5\ \text{А}.}$
5. Неверно: ${P = UI = 3 \cdot 3 = 9\ \text{Вт}.}$

Ответ: 123.
