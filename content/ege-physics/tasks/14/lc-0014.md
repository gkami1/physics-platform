В идеальном колебательном контуре происходят свободные электромагнитные колебания. Сила тока в катушке в разные моменты времени:

- ${t = 0:}$ ${I = 0;}$
- ${t = 2\ \text{мкс}:}$ ${I = 2{,}83\ \text{мА};}$
- ${t = 4\ \text{мкс}:}$ ${I = 4\ \text{мА};}$
- ${t = 6\ \text{мкс}:}$ ${I = 2{,}83\ \text{мА};}$
- ${t = 8\ \text{мкс}:}$ ${I = 0;}$
- ${t = 10\ \text{мкс}:}$ ${I = -2{,}83\ \text{мА};}$
- ${t = 12\ \text{мкс}:}$ ${I = -4\ \text{мА};}$
- ${t = 14\ \text{мкс}:}$ ${I = -2{,}83\ \text{мА};}$
- ${t = 16\ \text{мкс}:}$ ${I = 0.}$

Из приведённого ниже списка выберите все верные утверждения.

1. Период колебаний равен ${16\ \text{мкс}.}$
2. Частота колебаний равна ${62{,}5\ \text{кГц}.}$
3. В момент ${t = 4\ \text{мкс}}$ энергия электрического поля конденсатора максимальна.
4. В момент ${t = 8\ \text{мкс}}$ модуль заряда конденсатора максимален.
5. В момент ${t = 12\ \text{мкс}}$ энергия магнитного поля катушки равна нулю.

## Решение

1. Верно: ток повторяет свои значения через ${16\ \text{мкс}.}$
2. Верно: ${\nu = \dfrac{1}{16 \cdot 10^{-6}} = 62\,500\ \text{Гц}.}$
3. Неверно: ток максимален — вся энергия в катушке, энергия конденсатора равна нулю.
4. Верно: ток равен нулю — конденсатор заряжен максимально.
5. Неверно: ${|I| = 4\ \text{мА}}$ — наибольший, энергия катушки максимальна.

Ответ: 124.
