Спутник массой $m$ обращается вокруг планеты массой $M$ по круговой орбите радиусом $r.$ $G$ — гравитационная постоянная.

Установите соответствие между физическими величинами и формулами, по которым их можно рассчитать. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

**Физические величины**

А) модуль скорости спутника
Б) период обращения спутника

**Формулы**

1) $\sqrt{GMr}$
2) $2\pi\sqrt{\dfrac{r^3}{GM}}$
3) $\dfrac{GM}{r^2}$
4) $\sqrt{\dfrac{GM}{r}}$

Запишите в ответ цифры, расположив их в порядке, соответствующем буквам: А, Б.

## Решение

А) Из ${\dfrac{mv^2}{r} = G\dfrac{mM}{r^2}}$ получаем ${v = \sqrt{\dfrac{GM}{r}}}$ — формула 4.

Б) ${T = \dfrac{2\pi r}{v} = 2\pi r\sqrt{\dfrac{r}{GM}} = 2\pi\sqrt{\dfrac{r^3}{GM}}}$ — формула 2. Формула 3 — центростремительное ускорение спутника.

Ответ: 42.
