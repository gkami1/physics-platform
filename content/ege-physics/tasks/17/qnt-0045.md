Металлическую пластину освещают светом частотой $\nu$, и наблюдается фотоэффект. Работа выхода электронов из металла $A$, $h$ — постоянная Планка.

Установите соответствие между физическими величинами и формулами, по которым их можно рассчитать. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

**Физические величины**

А) максимальная кинетическая энергия фотоэлектронов
Б) частота, соответствующая красной границе фотоэффекта для этого металла

**Формулы**

1) ${h\nu + A}$
2) ${h\nu - A}$
3) ${A h}$
4) ${\dfrac{A}{h}}$

Запишите в ответ цифры, расположив их в порядке, соответствующем буквам: А, Б.

## Решение

А) Из уравнения Эйнштейна ${h\nu = A + E_\text{к max}}$ получаем ${E_\text{к max} = h\nu - A}$ — формула 2.

Б) На красной границе ${E_\text{к max} = 0,}$ ${h\nu_\text{кр} = A,}$ ${\nu_\text{кр} = \dfrac{A}{h}}$ — формула 4.

Ответ: 24.
